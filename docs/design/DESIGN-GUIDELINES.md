# デザイン規範（DESIGN-GUIDELINES）

> **このファイルはAI実装の必読規範**。UI/UXに触れる全チケットは本規範に適合すること。
> 根拠と出典は `docs/design/UX-RESEARCH.md`。改訂は設計者（計画書レベルの変更として）が行う。

## 1. フィードバック原則（最優先）

- **200ms規範**: ユーザー操作には200ms以内に何らかの視覚応答を返す（押下状態・スピナー・スケルトン・disabled化のいずれか）。「押したのに無反応」を全廃する
- **1秒規範**: 1秒を超えうる処理は進捗表示（可能なら%）と中断手段を必ず付ける（日影マップ方式を全処理の標準にする）
- **結果の所在**: 操作の結果がどこに現れたかを視線移動なしで分からせる（出現位置のトランジション・ハイライト1回点滅など、意味のあるモーションで示す）
- 楽観的UI: 成否が確実な操作（トグル・折りたたみ）は即時反映。失敗しうる操作（データ取得）は取得中状態を挟む

## 2. モーション体系（トークン駆動）

`style.css` 冒頭のデザイントークンのみを使用。**個別の直書きduration/easing禁止**:

```css
:root {
  --duration-instant: 100ms;  /* 押下状態・ハイライト */
  --duration-fast: 180ms;     /* フェード・折りたたみ */
  --duration-base: 250ms;     /* パネル・カードの出入り */
  --duration-sheet: 320ms;    /* ボトムシートのスナップ */
  --ease-out: cubic-bezier(0.2, 0, 0, 1);      /* 出現・移動（減速） */
  --ease-in: cubic-bezier(0.3, 0, 1, 1);       /* 退出（加速） */
  --ease-spring: cubic-bezier(0.34, 1.3, 0.64, 1); /* シートスナップのみ */
}
@media (prefers-reduced-motion: reduce) {
  :root { --duration-instant: 0ms; --duration-fast: 0ms; --duration-base: 0ms; --duration-sheet: 0ms; }
}
```

- モーションは**因果・空間関係を伝える目的のみ**（装飾アニメ禁止）。最長500ms
- reduced-motion はトークン一括ゼロ化で対応（個別対応の分散禁止）

## 3. タッチ・モバイル

- タッチターゲット最小 **44×44px**（見た目が小さくても hit 領域を padding/擬似要素で確保）
- ボトムシート: 速度スナップ（既存）+ **地図連動**（シート高さに応じ注視点をオフセットし、診断地点がシートに隠れない）
- hover のみに依存する операции禁止（タッチに等価手段を用意）
- シート内スクロールとシートドラッグの競合は「full状態のみ内部スクロール」（既存規範を維持）

## 4. 動線

- **主要ユースケースは2タップ以内**: 「現在地を診断」「地図タップ→診断」「検索→診断」
- 左パネルは折りたたみ既定・使用頻度順。画面の主役は常に地図（パネルの常時展開で地図を圧迫しない）
- 同時に1つ: モーダル的UI（診断カード・日影マップ計算）は排他（既存規範を維持）

## 5. 性能の体感

- requestRenderMode時の描画発火漏れは**UIバグとして扱う**（表示が変わる全操作の直後に scene.requestRender()）
- INP目標: 主要操作で **200ms未満**（CIはSwiftShaderのため実機チェックリストで確認）。LoAF（50ms超フレーム）を計測フックで数え、増加はリグレッション
- 初期表示: モバイル軽量モードでLOD1表示5秒以内（R8a基準を維持）

## 6. AIレビュー動線

- UI変更チケットの完了条件に「`test/capture-*-shots.mjs` 相当のスクショ更新 + DOM/a11y構造の e2e アサート」を含める
- レビューは視覚判定より **DOM構造・計測値（INP/LoAFカウント・要素の状態遷移）** を優先（決定的であるため）
