## 1. 中野四季の森公園周辺（200m／10m）

1. スポット移動の「サンプラザ跡・四季の森」を選び、建物の読込みが落ち着くまで待つ。
2. 日影マップの「計算する」を押すと同時に計時を始める。
3. 計算中に地図をパン・ズーム・回転し、操作の追従性を確認する。

- [ ] 最初の40mブロックが、点状ではなく対象範囲の全面を覆って5秒以内に表示される
- [ ] 40m→20m→10mの順で表示が精細化し、進捗が100%・「計算完了」になる
- [ ] 初回の200m／10m計算が30秒以内に完了する
- [ ] 計算中も地図のパン・ズーム・回転が滑らかで、操作不能になる長い停止がない
- [ ] ビル北側が濃い影、公園が明るい分布として視認できる
- [ ] 上記分布が分かる全景スクリーンショットを取得した

## 2. 中野駅前の建物（1階と屋上）

1. スポット移動の「中野駅」を選び、駅前の十分な高さがある建物をクリックする。
2. 診断カードの日照セクションで、視点高さが「1階」の状態にある冬至の日照時間を記録する。
3. 視点高さを「屋上」へ変更すると同時に計時し、再計算後の冬至の日照時間を記録する。

- [ ] 建物クリック時の視点高さセレクタに「屋上」と各階が表示される
- [ ] 1階と屋上の冬至日照に明確な差がある（屋上が1階以上、かつ差が0.5時間以上）
- [ ] 屋上への変更後、日照だけの再計算が2秒以内に完了する
- [ ] 再計算中は旧タイムラインが薄く残り、進捗が表示される
- [ ] 完了後の注記に屋上の視点高さが表示される

## 7. Cesium依存更新時の運用

`scene.pickFromRay` と `scene.pickFromRayMostDetailed` は非公開APIを含むため、Cesiumのバージョンを変更したときは通常のテストに加えて、必ず次を実施する。

```bash
npm run serve
# 別ターミナルで
node test/r3-probe.mjs
```

- [ ] `test/r3-probe.mjs` が完走し、`pickFromRayMostDetailed` の解決、同期`pickFromRay`、建物フィーチャ単位の除外、`sampleHeightMostDetailed`、メモリ統計、階数プロパティを再確認した
- [ ] 計測値とAPI挙動を `docs/plans/R3.md` または依存更新の実装記録へ残した
- [ ] 非公開APIの挙動が変わった場合はリリースを止め、フォールバックを含む設計を再確認した
