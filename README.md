# 中野区 3D都市モデルビューア + 街カルテ（nakano-3d）

東京都中野区全域を3Dで表示するWebアプリです。国土交通省 [Project PLATEAU](https://www.mlit.go.jp/plateau/) の中野区 3D都市モデル（2025年度版）をストリーミング配信で読み込み、CesiumJSで描画します。ビルドや3Dデータのダウンロードは不要で、`index.html` を開くだけで動きます。

住所を入力するか地図をクリックすると、その地点の **洪水浸水想定・土砂災害警戒区域・用途地域・日照時間** をまとめた「**街カルテ**」を表示します。診断結果は **URLで共有**でき、**最大3地点を並べて比較**したり、**用途地域を地図に色分け表示**したりできます。

## デモ

GitHub Pages: https://y-kanekoo.github.io/nakano-3d/

**初回のみ有効化が必要です**（GitHub Actionsのトークンでは自動有効化できないため）:

1. リポジトリの **Settings → Pages** を開く
2. 「Build and deployment」の **Source** を **GitHub Actions** にする
3. **Actions** タブから「Deploy to GitHub Pages」ワークフローを **Re-run**（または何かをpush）

以降はmainへのpushごとに自動デプロイされます。

## 機能

### 街カルテ（地点診断）

画面上部の検索ボックスに住所を入れるか、左パネルの「地点を診断」をONにして地図をクリックすると、その地点の診断カードが開きます。建物をクリックした場合は建物属性も一緒に表示されます。

| セクション | 内容 | データ元 |
|---|---|---|
| 📍 地点 | 住所（検索時）と経緯度 | 国土地理院 住所検索API |
| 🌊 洪水浸水想定 | 想定最大規模の浸水深ランク（区域外 / 0.5m未満 / 0.5〜3.0m / … / 20.0m以上） | ハザードマップポータル |
| ⛰️ 土砂災害警戒区域 | 土石流・急傾斜地の崩壊・地すべりの3種を、区域外 / 警戒区域（イエロー）/ 特別警戒区域（レッド）で判定 | ハザードマップポータル |
| 🏘️ 都市計画 | 用途地域・建蔽率・容積率・敷地面積の最低限度・防火地域・高度地区 | PLATEAU 都市計画決定情報（MVT） |
| ☀️ 日照 | 冬至・春分・夏至それぞれの日照時間（7:00〜17:00 JST）と時刻帯の横棒タイムライン | 建物3D Tilesへのレイキャスト＋NOAAの太陽位置計算 |
| 🏢 建物 | 計測高さ・用途・階数などのCityGML属性（建物クリック時のみ） | PLATEAU 建築物モデル |

各項目は独立して非同期に取得され、取得でき次第カードに埋まります。1つの項目が失敗しても他の項目には影響しません。

判定のしくみ:

- **洪水・土砂災害** — 該当地点のラスタタイル（z=16 PNG）を1枚取得し、canvasで地点ピクセルの色を読んで凡例色と照合します（最近傍色。距離が離れすぎる場合は「判定不能」）。透明ピクセルとタイル404は区域外です。
- **都市計画** — PLATEAUのベクトルタイル（MVT, z=16）を取得・デコードし、点内包判定（ray-casting・偶奇規則）で該当ポリゴンの属性を読みます。区境をまたぐ地点でも正しく判定できるよう、タイルに含まれる隣接区のポリゴンも除外していません。
- **日照** — 地点の地表+1.2mから太陽方向へレイを飛ばし、`scene.pickFromRay` で建物との交差を調べます（1日31サンプル×3日＝93レイ）。計算前に地点上空へカメラを向け、周辺の建物タイルの読み込みを待ちます。

**日照の精度について**: 読み込み済みの建物タイルのみを考慮した簡易計算です。地形の起伏・画面外の建物・樹木は考慮していません。20分刻みのサンプリングで、太陽高度5度未満は日照に数えていません。あくまで目安としてご利用ください。

**表示される値は公的機関の公開データをそのまま判定した結果**であり、法的な効力はありません。正式な情報は各自治体の窓口・公式図面でご確認ください。

### 共有・比較・見える化

- **🔗 リンクをコピー** — 診断カードのヘッダから、いま見ている診断結果（地点・住所・カメラ画角・表示中の都市計画レイヤー）をURLハッシュに載せてコピーします。そのURLを開くと同じ画角・同じ地点の診断が自動で復元されます。形式は `#v=1&spot={lon},{lat}&addr=...&cam={lon},{lat},{height},{heading},{pitch}&ov=use,fire`。壊れたURLや日本国外の座標は黙って無視されます。
- **⚖ 比較に追加** — 最大3地点までスナップショットを貯め、画面下部の比較バーから比較表（洪水・土砂・用途地域・建蔽率・容積率・防火・高度地区・日照3値・建物高さ）を開きます。列ごとに「📍 地図で表示」「× 削除」ができ、比較状態も `#v=1&compare={lon},{lat};...` でURL共有できます（復元時は日照をスキップして「未計算」と表示します）。
- **都市計画レイヤー** — 左パネルから「用途地域」「防火・準防火地域」「高度地区」を地図に色分け表示できます。透明度は30〜80%で調整できます（初期55%）。PLATEAUのベクトルタイルをブラウザ内でcanvasにラスタライズする自前の `ImageryProvider` で描画しており、点診断とタイルのキャッシュを共用しています。配色は都市計画図の慣用配色に準拠し、右下の凡例と同じ定義（`js/config.js` の `USE_DISTRICT_COLORS`）を使っています。
- **UX** — 検索候補のキーボード操作（↑↓/Enter/Esc）、診断カードのセクション折りたたみ、直近5件の診断履歴、「📍 現在地を診断」に対応しています。対応エリア（中野区周辺）の外では建物3Dと日照が使えないため、その旨を表示したうえでハザードと都市計画のみ診断します。

### 3Dビューア

- **建物モデルの切り替え** — LOD2（テクスチャ付き・高精細）/ LOD2（テクスチャなし）/ LOD1（箱型・軽量）
- **高さによる色分け** — 建物の計測高さで5段階に色分け
- **影シミュレーション** — 影の表示と時刻スライダー（6:00〜18:00 JST）
- **防災レイヤー** — 洪水浸水想定区域（神田川流域・荒川水系）を半透明で重ね合わせ
- **道路（LOD3）・水部レイヤー**
- **スポット移動** — 中野駅、サンプラザ跡・四季の森公園、中野ブロードウェイ、新井薬師、哲学堂公園
- **背景地図切り替え** — 地理院の航空写真 / 淡色地図（都市計画レイヤーは背景を切り替えても残ります）

## ローカルでの実行

静的サイトなので、そのままHTTPサーバで配信するだけです（アプリ本体にビルド・npm依存はありません）。

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## テスト

テストのみnpm依存があります（アプリ本体は無依存のまま）。単体212項目 / スモーク17項目 / e2e 175項目（`e2e.test.mjs` 52 + `e2e-r1.test.mjs` 123）。

```bash
npm install

# 単体テスト（ブラウザ不要）: 太陽位置計算・タイル座標変換・ハザード判定・共有URL・比較・オーバーレイ
npm run test:unit

# 外部データを一切取りに行かない単体テスト（CIと同じ条件）
SKIP_NETWORK=1 npm run test:unit

# スモーク + e2e（Playwright + Chromium が必要。別ターミナルで python3 -m http.server 8123 を起動しておく）
npm run test:smoke
npm run test:e2e

# 外部タイルを直読みして期待値を確認し直す（データ更新時）
npm run expectations
```

## デプロイ後の手動確認

GitHub Pages 上では中継なしの素のCORSで動きます。デプロイ後は次を確認してください。

1. 「中野区中野五丁目」で検索 → カードに「洪水: 区域外 / 第1種中高層住居専用地域 建蔽率60% 容積率200%」が出る
2. 「中野区弥生町2丁目」で検索 → カードに「洪水: 0.5m未満 / 近隣商業地域 建蔽率80% 容積率400%」が出る
3. 日照セクションに冬至・春分・夏至の3本のタイムラインが出る（0hのまま止まらない）
4. 建物をクリックすると「🏢 建物」セクションに属性が出る
5. スマートフォン幅で検索バー・カードが画面内に収まる

## CI

`.github/workflows/ci.yml`:

- **push / PR** — Node 22 で `npm ci && npm run test:unit`。外部データ取得を伴う実タイル照合は `SKIP_NETWORK=1` でスキップします（外部サーバの都合でCIが赤くならないように）。
- **週次（月曜 12:00 JST）** — `SKIP_NETWORK` なしで実タイル照合込みの単体テストを実行し、失敗したらissueを自動起票します（外部データの更新検知）。
- **手動実行（workflow_dispatch）** — Chromiumを入れてスモーク＋e2eも回します。GitHub Actionsのランナーは外部へ直接出られるので `HARNESS_DIRECT=1`（中継なし）で動きます。スクリーンショットはartifactとして残ります。
